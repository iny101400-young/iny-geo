# 검색·AI 답변 기준 · 원본

**이 파일 하나가 원본이다.** 04·05·07·08 은 여기를 읽고, 자기 파일에 표를 다시 적지 않는다.

| 고칠 때 | |
|---|---|
| 새 근거를 읽었다 | **여기만 고친다.** 출처와 등급을 같이 적는다 |
| 스킬 규칙과 어긋난다 | **여기가 이긴다.** 스킬을 고친다 |
| 등급을 못 정하겠다 | **「근거 없음」으로 넣는다.** 빼지 않는다 |

## 1. 등급 넷 · 넣나 안 넣나

| 등급 | 어떻게 | 무엇 |
|---|---|---|
| **근거 있음** | **넣는다** | 검색이 실제로 쓰는 것 |
| **근거 없음 · 값이 안 든다** | **넣는다.** 「근거 없음」을 산출물에 적고 **08 이 잰다** | 반증됐거나 잰 연구가 없는 것 |
| **넣으면 거짓** | **안 넣는다** | 없는 것을 있다고 적게 되는 것 |
| **넣으면 손해** | **안 한다** | 얻는 것 없이 잃기만 하는 것 |

> **효과가 없다는 것과 거짓이라는 것은 다르다.**
> 효과 없는 건 넣고 잰다. 거짓은 안 넣는다.

**「값이 안 든다」의 조건은 자동으로 만들어질 때다.** 사람이 손으로 채워야 하는 것은 낡는다.
그건 값이 드는 것이고, **채울 자리가 없으면 안 넣는다.**

## 3. ★ X9 의 처방 · 이게 글쓰기 규칙의 뼈대다

반증 9번에 **무엇을 대신 하라는지**가 같이 적혀 있다.

> **형식적 질문 답변 블록을 제거하고, 그 질문들을 본문 작은 제목으로 승격해 실질 답변으로 만든다**

| | |
|---|---|
| **제거** | 기계용 질문 답변 블록만 붙이고 마는 것 |
| **승격** | **질문을 본문 작은 제목으로 쓴다.** 한 줄 걸고 마는 게 아니다 |
| **실질 답변** | 그 아래 답이 **본문의 실제 내용**이어야 한다 |

**깎인 건 속이 빈 포맷이지 질문이 아니다.**

| 질문형 제목 자체 | |
|---|---|
| 인용 | **78.4%** |
| 질문형 검색에서 AI 요약 발동 | **64.7%** |
| 그냥 검색에서 AI 요약 발동 | **13.7%** ← **짝이다. 같이 적는다** |

> **「질문을 쓰지 마라」로 읽히면 정반대로 간다. 옮길 때 반드시 같이 적는다.**

> **★ 두 숫자를 갈라 적지 않는다.** 64.7% 만 보면 높은 건지 알 수 없다.
> **13.7% 를 옆에 놔야 「약 4.7배」가 보인다.** 같은 연구(55,393 질의)의 짝이다.

### ★ 「사는 것」과 「길을 트는 것」을 가른다

**둘 다 「밖에 내 링크가 생기는 일」이라 한 줄로 적으면 전부 금지로 읽힌다.**

| | 무엇 | 우리 |
|---|---|---|
| **사는 것** | 링크 파는 데서 돈 주고 깐다 · 위성 사이트를 세운다 | **안 함** (상관 0.2) |
| **길을 트는 것** | **내가 쓴 글을 내 계정에서 소개한다** | **한다** |

**로봇은 링크를 눌러가며 돈다.** 밖에 글 주소가 걸려 있으면 첫 화면을 안 거치고 바로 그 글로 온다.

| 지킬 것 | |
|---|---|
| **목록 화면 말고 글 주소로** | 첫 화면은 로봇이 이미 온다. **글이 안 읽히는 게 문제다** |
| **자리마다 실효가 다르다** | 로그인해야 보이는 곳은 로봇이 못 읽는다. **완전히 공개된 곳이 세다** |
| **꼬리표를 붙인다** | 안 붙이면 어느 게시물이 사람을 데려왔는지 영영 모른다 |

## 7. 감사 도구가 시키는 것과 우리 판정

**바깥 감사 도구를 깔아서 그대로 돌리지 않는다. 아무것도 안 깔기 때문이다.**
**다만 무엇을 시키는지는 알아야 한다. 사용자가 다른 데서 그 말을 듣고 온다.**

> **★ 「안 쓴다」가 「안 배운다」는 아니다.**
> 좋은 항목이 있으면 **우리 잣대에 반영하고 8장에 출처를 남긴다.**
> 깔지 않는 까닭은 규칙이 아니라 실용이다 — **절반이 이미 있고, 남의 것은 관리가 끊길 수 있다.**

| 도구가 시키는 것 | 우리 | 왜 |
|---|---|---|
| 사이트맵 · 대표 주소 · 제목 · 요약 | **한다** | 근거 있음 |
| 그림글 | **한다** | 근거 있음 · 못 보는 사람에게 필요하다 |
| 고친 날짜 | **한다** | 근거 있음 |
| 로봇을 열어라 | **한다** | 근거 있음 |
| 기계가 읽는 표시를 채워라 | **한다** | **근거 없음.** X2. 이유를 바꿔 넣고 08 이 잰다 |
| `llms.txt` 를 만들어라 | **만든다** | **근거 없음.** X1. 자동이라 값이 안 든다 |
| 질문 답변 표시를 넣어라 | **넣는다** | **근거 없음.** X9. **질문이 본문에 글자로 있을 때만** |
| 첫 100자에 답과 숫자를 넣어라 | **요약 규칙으로만** | X8 이 걸린다. 확정 아님 |
| **회사 · 상품 · 가게 정보를 넣어라** | **안 넣는다** | **거짓.** 개인 사이트에 없다 |
| **AI 봇을 막아라** | **안 막는다** | **손해.** X12 |
| **알트에 목표 키워드를 넣어라** | **안 한다** | **거짓 + X7.** 남의 로고에 내 이름을 적는 것 |
| **「공짜 주소는 검색에 안 나온다」** | **사실이 아니다** | 무료로 받은 주소도 검색에 실린다. **다만 나중에 주소를 바꾸면 그동안 걸린 링크가 죽는다.** 겁을 줘서 사게 하지 않는다 |

### ★ 기계가 읽는 표시를 X2 에도 불구하고 넣는 이유

**늘어난다는 근거도 없고, 안 늘어난다는 반증도 이제 시작하는 사이트엔 안 맞는다.**
남는 건 **확실히 하는 일** 둘이다.

| 1 | **흩어진 계정이 같은 사람임을 알린다** |
| 2 | **검색 결과에 날짜와 저자가 붙는다** |

반증 자신이 이렇게 적어놨다 — **「리치 리절트 목적이면 유지. AI 인용 목적으로 우선순위 상단에 올리지 말 것」**

## 8. 참고한 곳

**백지에서 썼다. 코드를 가져온 곳이 없다.**

| | |
|---|---|
| **반증 열셋** · 효과 표 · 한계 둘 | 공개 리서치 종합. **원본은 01 이 모아 둔 재료 창고**에 줄마다 출처가 붙어 있다 |
| 대행사가 파는 항목 4계층 | 상동 · 재료 창고의 조사 문서 |
| 감사 항목 이름 | 공개 감사 도구 셋의 **공개 문서를 읽고 항목 이름만** 확인. **코드는 한 줄도 안 가져왔다** |
| 주소 · 대표 주소 · 로봇 · 사이트맵 · 그림글 | 검색 엔진 공개 문서 |
| 잣대 (`받아보기.sh` · `감사.sh` · `문장재기.sh`) | **직접 썼다.** `curl` 만 쓴다 |
| **같은 주소 여러 번 받아보기 · 이 화면으로 오는 링크 세기** | 공개된 색인 진단 스킬(MIT)에서 **항목 이름만** 가져왔다. **코드는 안 가져왔다.** 우리 `감사.sh` 에 얹었다 |

**국내 사람이 만든 자료는 기준에 안 들어갔다.** 5장의 「한국어 데이터가 없다」와 같은 자리다.
